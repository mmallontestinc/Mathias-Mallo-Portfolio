# Security and Disclosure Policy

This repository is a public-safe technical portfolio. It intentionally excludes proprietary source code, customer data, credentials, internal URLs, confidential audit evidence, private screenshots, and sensitive infrastructure details.

## Reporting a Concern

If you notice content that may expose sensitive information, please contact:

- Email: [mathias.mallo@icloud.com](mailto:mathias.mallo@icloud.com)
- GitHub: [github.com/mmallontestinc](https://github.com/mmallontestinc)

## Scope

In scope:

- Accidental exposure of private details in portfolio documentation
- Links or references that could reveal internal systems
- Sensitive data included by mistake

Out of scope:

- Requests for private source code
- Requests for customer or audit evidence
- Requests for internal infrastructure information

## Redaction Standard

All examples are generalized. System names, workflows, and architecture descriptions are public-safe summaries intended to demonstrate ownership, reasoning, and technical communication without disclosing confidential implementation details.
