# Privacy and Redaction

This repository is intentionally sanitized for public review.

## What Is Included

- Public-safe summaries
- Sanitized architecture overview pages
- Generalized Mermaid diagrams
- Case studies focused on role fit and impact
- Generic documentation templates

## What Is Not Included

- Proprietary source code
- Customer data
- Credentials
- Internal URLs
- Confidential audit evidence
- Private screenshots
- Internal infrastructure details
- Sensitive NTest implementation details
- Private operational runbooks

## Redaction Approach

Architecture is generalized. Source systems are described by category instead of exposing private locations or records. Project pages focus on problem, solution, architecture, technologies, and business impact.

## Review Principle

The goal is to demonstrate ownership, technical reasoning, compliance awareness, and documentation quality without exposing confidential information.
